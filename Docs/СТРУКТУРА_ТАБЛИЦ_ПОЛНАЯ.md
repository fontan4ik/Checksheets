## API Эндпоинты

### Ozon API

| Метод | Endpoint | Описание |
|-------|----------|----------|
| GET | v3/product/list | Список товаров (product_id) |
| GET | v4/product/info/attributes | Атрибуты товаров |
| GET | v4/product/info/stocks | Остатки FBO/FBS |
| GET | v5/product/info/prices | Цены |
| POST | v1/analytics/data | Аналитика продаж |
| GET | v1/product/info/stocks-by-warehouse/fbs | FBS по складам |
| GET | v3/product/info/list | Информация о товарах |

### Wildberries API

#### Statistics API

| Метод | Endpoint | Описание |
|-------|----------|----------|
| GET | /api/v1/supplier/stocks | Остатки на складах |
| GET | /api/v1/supplier/orders | Заказы за период |
| GET | /api/v2/list/goods/filter | Цены товаров |

#### Marketplace API

| Метод | Endpoint | Описание |
|-------|----------|----------|
| GET | /api/v3/warehouses | Список складов FBS |
| GET | /api/v3/stocks/{warehouseId} | Остатки по складу |

#### Content API

| Метод | Endpoint | Описание |
|-------|----------|----------|
| POST | /content/v2/get/cards/list | Список карточек |
| GET | /content/v1/nm/tariff | Информация о товарах |

## Точки входа

### Триггерные функции

```javascript
OzonMain()         // Ozon: товары, остатки, цены, SKU
WbMain()           // WB: остатки, заказы, цены, аналитика
OzonSKUAndAnalytic() // Ozon: аналитика (отдельно)
maintainArticleColumn() // Проверка артикулов
```

### Ручной запуск

```javascript
all()              // Все функции подряд
testAll()          // Тест всех функций
runOzonOnly()      // Только Ozon
runWbOnly()        // Только WB
runDiagnostics()   // Диагностика системы
```
