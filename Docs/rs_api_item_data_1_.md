# 1. Общие сведения APIвозвращает ответ в формате JSON.

При работе с API используется Basic авторизация, в качестве данных авторизации используются логин и пароль от RS24.ru. Параметры авторизации: Необходимо передавать заголовок Authorizationсо значением: Basic +переведенная в Base 64 строка, содержащая логин и пароль, разделенные символом «двоеточие». Например, для пары логина LOGINTESTи пароля Pass123456 строка «LOGINTEST: Pass123456» в Base 64будет выглядеть так: TE9HSU 5URVNUOl Bhc 3Mx Mj M0NTY= А заголовок целиком будет выглядеть следующим образом: Authorization: Basic TE9HSU 5URVNUOl Bhc 3Mx Mj M0NTY=

### Пример использования онлайндекодировщика для получения логина и пароля в Base 64:

1. Получаем список складов сидентификаторами, используя API со складами. Эта
