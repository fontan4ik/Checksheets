# Долгие триггеры Apps Script

Google ограничивает один запуск Apps Script шестью минутами и количество установленных триггеров — 20 на пользователя на проект. `ScriptApp.getProjectTriggers()` видит только триггеры текущего пользователя; удалить триггер другого пользователя этим API нельзя. Источники: [квоты](https://developers.google.com/apps-script/guides/services/quotas), [ScriptApp](https://developers.google.com/apps-script/reference/script/script-app).

| Функция с ошибками >10% | Изменение |
| --- | --- |
| `OzonMain` | Старый составной триггер больше не повторяет шесть уже отдельно запускаемых обновлений. |
| `updateProductsV2` | Не повторяет полный `syncOfferIdWithProductId`: у него есть собственный триггер. Обрабатывает до 8 000 товаров за запуск, сохраняет курсор и пишет только обработанные строки; следующий штатный запуск продолжает проход. |
| `updateOzonReviewCountBL` | Не запускает второй проход по ~244 тыс. отзывов; действующий локальный `ozon_reviews_local.js` обновляет BL. Ручной запасной вариант — `updateOzonReviewCountBLManual`. |
| `updateOzonFBOSales` | Длинный обход аналитики и FBS перенесён в локальный `ozon_fbo_fbs_sales_local.js`; AQ:AT записываются только после успешного сбора всех данных. |
| `startFetchAndWriteAnalytics` | Бюджет одного запуска снижен до 3 минут. Продолжение использует существующий триггер, если он есть; при заполненной квоте состояние сохраняется до следующего штатного запуска, который его не сбрасывает. |
| `updateStockFBO` | Не запускает повторно FBS обновление, которое уже имеет свой триггер; сохраняет курсор по SKU и продолжает на следующем штатном запуске после 3 минут. |
| `syncRSStocks` | Тяжёлую выгрузку Ozon/WB выполняет локальный `sync-rs-stocks.js` по расписанию 11:00/23:00; прежний Apps Script триггер не повторяет её. |

Новых триггеров Apps Script для продаж, отзывов, RS и FBO остатков нет. Продолжение аналитики может использовать один собственный временный триггер лишь при наличии свободной квоты. При недостатке места цикл продолжится позже по существующему штатному расписанию. Локальные задания отправляют ошибки в текущий Telegram канал.

При первом полном прогоне API Ozon отверг устаревший статус FBS `last_mile` (HTTP 400) и перечислил допустимые статусы. Он исключён из локального запроса; до исправления AQ:AT не записывались.

Повторный полный прогон завершился успешно: за 16 страниц месячной и 17 страниц квартальной аналитики были обработаны все поддерживаемые статусы FBS и записаны AQ:AT для 21 196 строк. Обратное чтение показало 20 712 непустых SKU в каждой из четырёх колонок.

Статистика ошибок в интерфейсе Google рассчитывается по прошлым запускам и не обнулится сразу после загрузки. Для проверки нужны новые выполнения. Жёсткий тайм-аут Apps Script не позволяет исполнить блок `catch`; его предупреждения видны в журнале Google, а локальные задания сообщают о ненулевом коде завершения.
