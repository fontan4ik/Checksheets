# Ручной тестовый остаток «Подорожник» — 21.10.2026

Пользователь предоставил скриншот переписки: сотрудник утром выставлял тестовый московский остаток, затем наблюдал обнуление и связывал его с Feron API; названа колонка «Подорожник». Скриншот — свидетельство ситуации, не команда повторно выставить остатки или отключить API.

На живой таблице найден соответствующий артикул LL-T8-10-230-65-G13-G-20, StreamSupps строка 189. В момент проверки I189 (FER MSK)=10 и M189 (ПОДОРОЖНИК ФБС)=10; обе клетки содержат числа, в M189 нет формулы. Прочие строки этого семейства могут содержать формулы распределения в M, поэтому значение M там зависит от исходного I и кратности.

feron_sync_local.py пишет исходные заголовки FER MSK/FER SMR/FER NSB/FER EKB (в текущем расположении I:L). Для отсутствующего в полном снимке товара/склада источник записывает явный 0. Это штатный refresh источника, ручной тест в I может исчезнуть при следующем проходе. Источник не пишет M. Дополнительно gsheets_utils.py READ_ONLY_COLUMN_HEADERS запрещает supplier-loader писать/очищать ПОДОРОЖНИК ФБС по видимому заголовку. sync-feron-stocks.js читает M как готовый московский остаток, не пересчитывает его по API Feron и не пишет обратно в лист.

WB payload audit подтверждает: 21.10 в 15:08:28 по Дубаю sync-feron-stocks подготовил amount=10 для chrtId=1376139422, склад 1449484 (ФБС ФЕРОН МОСКВА); item_result в 15:09:15 — amount=10, status=success. Записи amount=0 для этого же артикула на складе 798761 относятся к другому, самарскому складу и не доказывают обнуление Москвы.

Точное историческое событие «кем и когда изменена M» по скриншоту и текущим значениям не установлено. Две возможные ситуации различаются: ручное I заменяется штатным источником; M с формулой пересчитывается вслед за I. Вручную заданное числом M189=10 текущий источник не должен заменять, а новая append-only подготовка защищает все существующие строки.

В этом аудите данные листа и остатки маркетплейсов не изменялись. Снимок: test/runtime/podorozhnik-manual-live-20261021.json. Код: feron_sync_local.py, gsheets_utils.py, sync-feron-stocks.js. Журнал: logs/wb_stock_payload_audit_20261021.jsonl.
