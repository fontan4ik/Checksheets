# Локальный пересчёт листа ОБОР

`obor_summary_local.py` переносит логику Apps Script `updateOborSummary()` на локальный Python и обновляет семь колонок листа `ОБОР`.

Расписание LaunchAgent `com.checksheets.obor_summary`: ежедневно в 16:10 по часовому поясу компьютера (Asia/Dubai), между заданием в 15:15 и следующим крупным окном в 19:00. Запуск идёт с низким приоритетом. Ошибки отправляются через существующий Telegram-обработчик. Логи: `logs/obor_summary_launchd.log` и `logs/obor_summary_launchd.err`.

Ручной безопасный просмотр без записи:

```bash
.venv-etm-export/bin/python obor_summary_local.py --dry-run
```

Штатный ручной запуск с записью:

```bash
.venv-etm-export/bin/python obor_summary_local.py
```

WB-токен читается из `WB_API_TOKEN_FILE` или `~/AI agents/secrets/wb_api_token`, с резервным чтением действующего токена из `Shared_Настройки.js`; `WB_API_TOKEN` и `.env` поддерживаются как переопределения. `UNIT WB` выкуп API находится по заголовку `ВЫКУП ШТ API` (сейчас AO); AP содержит «ВОЗВРАТЫ API». `ТЕСТ!A` используется как фиксированная колонка артикула: в текущем листе её заголовок пустой. Пересчёт сначала читает источники и WB warehouse report, затем записывает значения одним пакетным запросом Google Sheets. Ozon FBS для КГТ СДЭК остаётся отключён.
