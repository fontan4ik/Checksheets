# Локальный пересчёт листа ОБОР

`obor_summary_local.py` переносит логику Apps Script `updateOborSummary()` на локальный Python и обновляет семь колонок листа `ОБОР`.

Расписание LaunchAgent `com.checksheets.obor_summary`: ежедневно в 03:20 по часовому поясу компьютера (Asia/Dubai). Запуск идёт с низким приоритетом. Ошибки отправляются через существующий Telegram-обработчик. Логи: `logs/obor_summary_launchd.log` и `logs/obor_summary_launchd.err`.

Ручной безопасный просмотр без записи:

```bash
.venv-etm-export/bin/python obor_summary_local.py --dry-run
```

Штатный ручной запуск с записью:

```bash
.venv-etm-export/bin/python obor_summary_local.py
```

Токен WB берётся из `Shared_Настройки.js`; при необходимости его можно переопределить через `WB_API_TOKEN` в окружении или локальном `.env`. Пересчёт сначала читает источники и WB warehouse report, затем записывает значения одним пакетным запросом Google Sheets. Ozon FBS для КГТ СДЭК остаётся отключён.
