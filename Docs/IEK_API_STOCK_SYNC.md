# IEK API: локальная синхронизация остатков

Источник анализа: `Downloads/openapi-new.json`, OpenAPI 3.0.3, версия API 1.4.638.

## API

- Корень API: `https://bp.iek.ru`.
- Авторизация: `POST /oauth/login`, форма `application/x-www-form-urlencoded`,
  `username=ticket`, `password=<API-ключ>`. Успешный запрос устанавливает куки
  `kc-access` и `kc-state` согласно спецификации. При фактическом запросе IEK
  вернул `bp-access` и `bp-state`; скрипт принимает обе пары и не сохраняет
  токены из тела ответа.
- `GET /api/catalog/v1/client/catalog` возвращает список верхнеуровневых
  категорий с `slug`.
- `GET /api/catalog/v1/client/category/{slug}/balances-json` возвращает дату
  снимка и массив `products`. У товара `article` — артикул, `available` — остаток;
  `warehouseData` содержит дополнительную разбивку по складам.
- `GET /api/catalog/v1/client/products/{article}` описан как карточка товара с
  ценами и остатками, но для синхронизации каталога используется пакетный метод
  `balances-json`, чтобы не делать запрос на каждую позицию отдельно. Для
  артикулов из листа, отсутствующих в пакетных файлах, скрипт проверяет эту
  карточку точечно; если API возвращает 404, ячейка остаётся пустой, а не
  превращается в ложный ноль.

В OpenAPI-спецификации не опубликованы схемы авторизации, лимиты запросов,
пагинация или ограничение частоты. Метод пакетных остатков описан через
`available`; при `null` значение в листе остаётся пустым, а не преобразуется в
ноль. Ошибки, дубликаты с противоречащим остатком и артикулы IEK из таблицы,
которых нет в каталоге, останавливают запись.

## Сопоставление с таблицей

- Рабочий лист в таблице с ID из `config.py` фактически называется `ТЕСТ`.
- Строки IEK выделяются по заголовку `Бренд`; API `article` сопоставляется с
  заголовком `МОДЕЛЬ`.
- Значение `available` записывается в заголовок `Остаток IEK`. Столбец создан
  справа от текущих данных (столбец 72); код также проверяет заголовок перед
  записью и создаёт его справа, если его нет.

## Локальный доступ и расписание

Скрипт `iek_stock_sync_local.py` использует `SourceAddressAdapter`, существующий
Google Sheets клиент проекта и общий lock/Telegram error wrapper.

API-ключ читается из macOS Keychain: service `checksheets-iek-api`, account
`ticket`. Переменная `IEK_API_KEY` предусмотрена как временный runtime fallback;
ключ не записывается в файлы проекта и не попадает в логи.

План запуска — каждый час в :52 через LaunchAgent
`com.checksheets.iek_stock_sync`, по принятому в проекте шаблону `launchd`.
Cron не используется для задач Checksheets. Агент не следует загружать до того,
как в Keychain появится API-ключ: пароль входа в личный кабинет API-ключом не
является. В профиле IEK сейчас отображается, что ключ ещё не выпущен.
