# НТЦ списания — запуск

Актуальный алгоритм, колонки, статусы заказов/возвратов и результаты тестов описаны в [«НТЦ — полный алгоритм и первый этап с F.md»](НТЦ%20—%20полный%20алгоритм%20и%20первый%20этап%20с%20F.md).

Локальная служба `com.checksheets.ntc_live_local` настроена через macOS LaunchAgent раз в минуту, но сейчас отключена по просьбе пользователя. При включённой работе она меняет F в листе «НТЦ списания» и локальный журнал, оставляя формулу I. API записи остатков на Ozon, WB или другие маркетплейсы не вызывается. Для проверки состояния:

```bash
launchctl print gui/$(id -u)/com.checksheets.ntc_live_local
tail -n 30 logs/ntc_live_launchd.log
tail -n 30 logs/ntc_live_launchd.err
```

Старый локальный `ntc_fbs_reserve_sync.py --apply` отключён. Старый Apps Script не является частью работающей цепочки. Дополнительные колонки L, M и N удалены; формула I берёт данные непосредственно из F.
