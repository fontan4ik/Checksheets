# Новые товары UNIT / StreamSupps / ТЗ — 21.10.2026

## Причины и исправления

1. `UNIT API` не входил в Ozon TARGETS автодобавления: ТЗ и StreamSupps уже содержали весь каталог из 23 199 предложений Ozon, UNIT отставал на 458 артикулов. В UNIT API добавлены точные ключи в A23795:A24252, запись проверена чтением. Каталог WB содержит 19 962 артикула, UNIT WB дополнений не требовал.
2. StreamSupps V1 (`РЕЗЕРВ`) и X1 (`РУССКИЙ СВЕТ МОСКВА`) оказались пустыми. Строгая схема останавливала все проходы. Восстановлены только прежние заголовки, с копией и проверкой отсутствия параллельных изменений. Кто и каким действием очистил заголовки, не установлено.
3. В UNIT API список A1 разворачивался из ТЕСТ. Дописывание новых ключей ниже этого массива создавало риск столкновения при росте ТЕСТ. Текущие A1:A24252 материализованы с точным сохранением типов/порядка/значений; форматирование и другие колонки сохранены. Будущая запись UNIT требует обычного заголовка Артикул.
4. Новые строки не имели всех построчных расчётов. Добавлен локальный `catalog_formulas_local.js`, вызываемый onboarding для управляемых новых товаров, с защитой старых строк и ручных значений.

## Оставшиеся исключения

- `32491DEK-1`: прежний отказ Ozon `OVER_MAX_OVH_NON_KGT`; подтверждение не присваивается.
- `32890DEK-1`: единица поставщика не «шт», требуется проверка, автоматическая отправка заблокирована.
- Пять артикулов с брендом SBER (`ATN000145Z-1`, `ATN000117Z-1/-10/-5`, `ATN000138Z-1`): производитель в ЭТМ отличается от бренда Ozon, код не угадывается. Это отдельные позиции, а не пропуск кодов Systeme Electric.
- Три незавершённые карточки ATN001219-1/-5/-10 без SKU/кратности не отправляются; бренд и прочие доступные метаданные загружены.
- Старая лента ИЭК `LSR2-2-030-20-3-05-1`: Ozon продаёт одну бухту 5 м. Единица Русского Света не подтверждена точным товаром в доступной проверке; строка оставлена без изменения, перевод метров в бухты не придуман. У прочих проверенных реальных ИЭК коды уже существовали.
- Старый Systeme `PA16-007B-1` сохраняет прежний CODES="-"; неподтверждённый ETM-код не подставлялся. Восстановлены недостающие формулы, RS-источник доступен.
