Headers:
  Authorization: server ZjA5MDg3MTAtNjQ5ZS00ODU5LWJjNjktY2NkY2E1ZDdlNjUx
  Content-Type: application/json

Body:
  {"size": 100}

Response:
  {
    "items": [
      {
        "product_id": "000871e6-cfb0-11e9-812f-b0c554fff378",

        "brand": "FERON",
        ...

    "search_token": "..."

ВАЖНО:
  • API требует UUID товара (product_id), а не артикул
  • Минимальный размер выборки: 10 товаров
  • Поле "limited": true означает, что показано ограниченное количество
  • Rate limiting: рекомендуется 2 секунды между запросами

🚀 СЛЕДУЮЩИЕ ШАГИ ДЛЯ ЗАПУСКА (30 МИНУТ)
═══════════════════════════════════════════════════════════════════════════════

1. Создать config.py (2 минуты)
   ────────────────────────────────────────────────────────────────────────
   cp config_example.py config.py

   Файл уже содержит все необходимые данные!

2. Настроить Google Sheets (10 минут)
   ────────────────────────────────────────────────────────────────────────
   • Создать таблицу с листом "Feron"
   • Добавить колонки: A (Артикул продавца), B (Модель), J (chrtId)
   • Добавить колонки остатков: Ферон Самара, Ферон Внуково, Ферон Новосибирск
   • Добавить Google Apps Script из файла "Синхронизация остатков Feron.gs"
   • Настроить Script Properties (OZON_CLIENT_ID, OZON_API_KEY, WB_API_KEY)
   • Развернуть как веб-приложение

3. Установить зависимости Python (2 минуты)
   ────────────────────────────────────────────────────────────────────────
   pip install requests gspread oauth2client

4. Создать gsheets_utils.py (5 минут)
   ────────────────────────────────────────────────────────────────────────
   Реализовать функции:
   - get_worksheet()
   - clear_column()
   - update_column_by_header()

5. Получить credentials.json (5 минут)
   ────────────────────────────────────────────────────────────────────────
   • Google Cloud Console → Создать проект
   • Включить Google Sheets API
   • Создать Service Account
   • Скачать JSON ключ

6. Запустить тестирование (5 минут)
   ────────────────────────────────────────────────────────────────────────
   python feron_sync_local.py

7. Настроить автоматизацию (5 минут)
   ────────────────────────────────────────────────────────────────────────
   • Регламентное задание в 1С (каждые 4 часа)
   • Task Scheduler для Python (каждые 4 часа)
   • Триггер в Google Apps Script (каждые 4 часа)
