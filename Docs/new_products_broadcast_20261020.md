## Единицы кабеля: обязательное исключение

Модели `LC1-C5E04-121-T-R`, `LC1-C5E04-121-T-P-R`, `LC1-C5E04-321-T-P-R`, `LC1-C5E04-311`, `LC1-C5E04-111-T-R` продаются в Ozon бухтами 305 м при F=1.

ЭТМ возвращает для этих кодов метры: только в их S установлено `ROUND(TRUNC(Q/305)/F/1,5;0)`. Q сохраняет единицы источника. Эти пять кодов отсутствуют в текущих выбранных FTP-выгрузках; актуальный остаток ЭТМ для них нулевой. Ещё две модели кабеля имеют подтверждённую единицу ЭТМ `упак` с длиной 305 м и не требуют такого деления.

РС также возвращает метры, но `qtyLots` содержит отдельные отрезки. Складывать короткие отрезки в виртуальную бухту запрещено. Например, 464 м модели `LC1-C5E04-311` состояли из восьми отрезков не длиннее 133 м: полных бухт нет.

`rs_sync_local.py` для этих пяти точных моделей получает `/residue/{warehouse}/{code}`, проверяет единицу 006, неотрицательные количества и совпадение суммы `qtyLots` с `Residue`, затем суммирует целую часть каждого отрезка / 305. Партнёрские остатки не прибавляются. **Именно для этих пяти моделей U:RS SMR хранит количество полных секций 305 м, а не метры**; V использует прежний запас /1,5 и кратность F. W:RS MSK не преобразуется.

Проверенные количества в U: 0, 3, 1, 0, 8; V после запаса: 0, 2, 1, 0, 5. Штатное правило транслятора дополнительно обнуляет остаток 1 для не-Arlight. Отсутствующие или противоречивые данные о положительном остатке прерывают источник до записи; подтверждённый нулевой остаток допускается без отрезков.

## Почему не подготовилось автоматически

1. Новые строки появились после ежедневного запуска CODES в 08:30 Dubai. Он видел прежние 21 997 строк. Обновление остатков ЭТМ пропускает уже обработанный FTP-файл, поэтому после новых кодов нужен повторный проход источника.
2. В новых строках не были продолжены формулы M/N/AB/AC.
3. Дневной РС завершился ошибкой изменения пагинации во время чтения; повторный запуск успешно получил полный снимок.
4. Отдельно обнаружен сбой почасового добавления артикулов: `catalog_articles_local.js` отвергал документированный пустой A1 StreamSupps. Проверка исправлена через общий resolver; неизвестные, перенесённые и дублирующиеся заголовки по-прежнему отклоняются. Основной каталог специально не запускался, чтобы не добавлять другие товары в этот объём.
