# Проверка CPC 6 октября 2026

В листе `СРС` 1414 строк с артикулом/SKU. Для новых строк создано сегодня
204 кампании. На проверке все 204 были активны в Ozon. До исправления последние
четыре строки (1412–1415) не имели CAMPAIN ID: Ozon возвращал HTTP 429
для метода ExtAddProducts.

Восстановлены существующие незавершённые кампании:

| Артикул | SKU | Кампания |
|---|---|---|
| 41967-1 | 3237176996 | 44581472 |
| 50063-1 | 2550807018 | 44581473 |
| 48732-5 | 1643090250 | 44581474 |
| 49036-1 | 2554692791 | 44581475 |

Для каждой проверены фактический SKU, состояние CAMPAIGN_STATE_RUNNING и
ставка 8000000 микрорублей (8 ₽). Переключатель 1, дневной лимит 3 клика,
месячный лимит ДРР 5%; на проверке запрета включения не было.
Повторная попытка добавления SKU завершилась успешно: точный период лимита
из ответа API не известен, исчерпание суточной общей квоты не подтверждено.

## Исправления

- `create_ozon_cpc_campaigns.py`: сохраняет ID незавершённой кампании до
  добавления товара в `logs/cpc-creation-state.json`; восстанавливает ранее
  созданные несвязанные кампании по имени и проверяет их состав; повторяет
  HTTP 429 с паузами 5/15 секунд; прекращает создание остальной очереди при
  сохранении 429; учитывает переключатель и фильтры до активации.
- ID записывается в точную строку после добавления товара. Неуспешный запуск
  возвращает код 1 даже при успешной аналитике: существующая Telegram-обёртка
  сможет сообщить о проблеме. Привязки Telegram не изменялись.
- Чтение листа в создании кампаний и синхронизации ставок использует общий
  retry Google Sheets для временных разрывов соединения.
- Добавлены проверки повторного запуска после 429, восстановления существующей
  кампании и соблюдения переключателя/фильтров. Все 57 CPC-тестов прошли.

Запуск по действующему LaunchAgent обновил дневные метрики всех 1414 строк и
статусы новых кампаний. Дневной фильтр реально остановил старые кампании при
достижении лимита кликов. Неделя/месяц обновляются порциями по ротации.

## Общий журнал

Проверены `logs/script_errors.jsonl` и вкладка `Лог ошибок`.
Среди ошибок CPC за 1–5 октября встречались разрывы Google-соединения и
недоступность сети. Последние проверки ставок и переключения успешны.
Сбой добавления товара раньше не попадал в общий журнал из-за кода завершения 0.

Вне CPC есть самостоятельные сбои: автоодобрение скидок Ozon возвращает
«Заявка не найдена»; получение выкупов Ozon достигает ограничения Seller API;
WB сообщает о расхождениях после проверки остатков. 4 октября записан ENOSPC;
на проверке файловая система имела около 11 GiB свободного места.
Эти записи не доказывают сбой рекламных кампаний и требуют отдельной диагностики.
