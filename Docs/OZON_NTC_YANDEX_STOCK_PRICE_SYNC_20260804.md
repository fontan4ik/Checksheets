# Ozon НТЦ → UNIT YNX → Яндекс Маркет

Дата: 2026-08-04

## Назначение

`Синхронизация остатков Ozon НТЦ в Яндекс.js` реализует единый ручной запуск `syncOzonNtcStocksToYandex()`:

1. Находит в Ozon ровно один FBS-склад по точному имени `НТЦ СКЛАД`.
2. Считывает остаток по Ozon SKU для товаров, сопоставленных `UNIT YNX!A` ↔ `ТЕСТ!A`, где SKU Ozon находится в `ТЕСТ!V`.
3. Записывает остатки в `UNIT YNX!Y` (`НТЦ STOCK`).
4. Передаёт эти остатки в кампанию Яндекс Маркета.
5. Передаёт цены из `UNIT YNX!T` (`Целевая цена`) в ту же кампанию Яндекс Маркета.

## Защиты

- Скрипт не создаёт, не меняет и не удаляет триггеры.
- Перед первой записью проверяются заголовки `T = Целевая цена` и `Y` с `НТЦ`/`STOCK`.
- Склад Ozon выбирается только точным совпадением имени; ноль или несколько совпадений останавливают запуск.
- Некорректная/пустая целевая цена останавливает запуск до записей в Google Sheets и Яндекс.
- API-Key Яндекс Маркета задаётся вручную в `settings.js` в константе `YANDEX_MARKET_API_KEY_VALUE`; не добавляйте этот файл с заполненным ключом в публичный Git.
- Цена передаётся только store-specific методом `POST /v2/campaigns/{campaignId}/offer-prices/updates`; при недоступности индивидуальных цен скрипт завершится с ошибкой, а не переключится молча на общий business-level метод.

## Ручная настройка и запуск

1. В `settings.js` заполнить `YANDEX_MARKET_API_KEY_VALUE`.
2. Выполнить `verifyYandexNtcConfiguration()` — только read-only проверка доступа и кампании.
3. Выполнить `syncOzonNtcStocksToYandex()` для обновления остатков и цен.

## API-документация

- Ozon Seller API: `POST /v2/warehouse/list`, `POST /v2/product/info/stocks-by-warehouse/fbs`.
- Яндекс Маркет: `PUT /v2/campaigns/{campaignId}/offers/stocks`, `POST /v2/campaigns/{campaignId}/offer-prices/updates`.
- Официальная OpenAPI-спецификация Яндекс Маркета проверена на 2026-08-04: для цен требуется массив `offers` до 2000 объектов `{offerId, price:{value,currencyId}}`; для остатков — `skus` до 2000 объектов `{sku,items:[{count}]}`.

Откат к предыдущему исходнику: восстановить оба файла из backup, загрузить в Apps Script и подтвердить cloud read-back. Уже отправленные в Яндекс остатки/цены кодом не откатываются: для них потребуется отдельная явно подтверждённая операция.
