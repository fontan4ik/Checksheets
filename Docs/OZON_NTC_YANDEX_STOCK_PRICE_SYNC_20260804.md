# Ozon НТЦ → UNIT YNX → Яндекс Маркет

Дата: 2026-08-04

## Назначение

`Синхронизация остатков Ozon НТЦ в Яндекс.js` теперь содержит три независимые ручные функции:

1. `syncOzonNtcStocksToUnitYnx()` — Ozon НТЦ СКЛАД → `UNIT YNX!Y` (`НТЦ STOCK`) по артикулу: `UNIT YNX!A` ↔ `ТЕСТ!A`, Ozon SKU из `ТЕСТ!V`. В Яндекс не пишет.
2. `syncUnitYnxNtcStocksToYandex()` — отправляет в Яндекс только уже загруженные значения `UNIT YNX!A/Y`. Ozon и таблицу не читает/не меняет.
3. `syncUnitYnxPricesToYandex()` — отправляет в Яндекс только цены `UNIT YNX!A/T` (`Целевая цена`). Остатки и Ozon не трогает.

Ранее единый запуск `syncOzonNtcStocksToYandex()` объединял все три тяжёлых этапа и по журналу Apps Script достиг лимита времени 360 секунд. Старый entrypoint удалён, чтобы не запускать длинную цепочку повторно.

## Защиты

- Скрипт не создаёт, не меняет и не удаляет триггеры.
- Каждая функция проверяет только нужный ей заголовок: загрузка остатков — `Y` с `НТЦ`/`STOCK`; цены — `T = Целевая цена`.
- Загрузка из Ozon выбирает склад только точным совпадением имени `НТЦ СКЛАД`; ноль или несколько совпадений останавливают запуск.
- Пустой или некорректный остаток в `Y` останавливает передачу остатков в Яндекс **до первого API-вызова Яндекс**.
- Некорректная/пустая целевая цена останавливает передачу цен в Яндекс **до первого API-вызова Яндекс**.
- API-Key Яндекс Маркета задаётся вручную в `settings.js` в константе `YANDEX_MARKET_API_KEY_VALUE`; не добавляйте этот файл с заполненным ключом в публичный Git.
- Цена передаётся только store-specific методом `POST /v2/campaigns/{campaignId}/offer-prices/updates`; при недоступности индивидуальных цен скрипт завершится с ошибкой, а не переключится молча на общий business-level метод.
- Лимит Яндекса для цен — 10 000 SKU в минуту: после каждых 10 000 цен скрипт ждёт 61 секунду; HTTP 420 для цены получает одну такую же повторную попытку.

## Ручная настройка и запуск

1. В `settings.js` должна быть заполнена `YANDEX_MARKET_API_KEY_VALUE`.
2. Выполнить `verifyYandexNtcConfiguration()` — только read-only проверка доступа и кампании.
3. Выполнить `syncOzonNtcStocksToUnitYnx()` — обновляет только `UNIT YNX!Y`.
4. После read-back `Y` выполнить `syncUnitYnxNtcStocksToYandex()` — передаёт только остатки в Яндекс.
5. Выполнить `syncUnitYnxPricesToYandex()` — передаёт только цены в Яндекс.

## API-документация

- Ozon Seller API: `POST /v2/warehouse/list`, `POST /v2/product/info/stocks-by-warehouse/fbs`.
- Яндекс Маркет: `PUT /v2/campaigns/{campaignId}/offers/stocks`, `POST /v2/campaigns/{campaignId}/offer-prices/updates`.
- Официальная OpenAPI-спецификация Яндекс Маркета проверена на 2026-08-04: для цен требуется массив `offers` до 2000 объектов `{offerId, price:{value,currencyId}}`; для остатков — `skus` до 2000 объектов `{sku,items:[{count}]}`.
