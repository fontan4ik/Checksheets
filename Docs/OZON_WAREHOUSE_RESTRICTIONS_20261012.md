# Ozon: ограничения габаритов, 12 октября 2026

Проверены логи 5–11 октября и read-only API `/v2/warehouse/list`, `/v3/product/info/list`, `/v4/product/info/attributes`. В логах найден 51 артикул с `OVER_MAX_OVH_NON_KGT`. Это ограничение совместимости товара со складом; повторная запись остатка его не устраняет. Ни габариты, ни привязки складов, ни остатки не изменялись.

Склады «МОСКВА» (1020005000217829), «ФЕРОН САМАРА» (1020005000234124), «РУССКИЙ СВЕТ» (1020005005049870), «РУССКИЙ СВЕТ МОСКВА» (1020005030719640) имеют `is_kgt=false`. Для восстановления продаж требуется корректный склад КГТ либо исправление только фактически ошибочных габаритов карточки. Автоматическое уменьшение реальных размеров недопустимо.
