# Автоматическое подключение новых товаров StreamSupps

Установлено 20.10.2026. Владелец процесса: `stream_onboarding_local.js`.

## Запуск и порядок

LaunchAgent `com.checksheets.stream-onboarding` с 21.10.2026 проверяет лист каждые 2 часа (7200 секунд); отдельный WatchPaths-запуск после обновления каталога отключён. Он работает на этом Mac при активной пользовательской сессии. Первичное обнаружение сохраняется по артикулу продавца: новые строки, включая вставленные в середину листа, автоматически подхватываются. Историческая база до строки 22487 инициализирована однократно, повторная массовая отправка старого каталога не выполняется.

1. Получить точные SKU Ozon, бренд и кратность упаковки из каталога Ozon. Скрытый лист `_STREAM_ONBOARDING_CATALOG` служит резервным источником бренда/SKU, пока основной каталог `ТЕСТ` не заполнен. Положительные данные основного каталога имеют приоритет.
2. Дополнить только отсутствующие значения и формулы F/H/M/N/S/V/AB/AC/AE в выбранных новых строках. Существующие ручные значения сохраняются. Кратность из суффикса артикула не выводится; используются явный атрибут Ozon 8962 либо однозначное существующее соответствие. Длина кабеля требует проверки единиц.
3. Заполнить пустые CODES по точному артикулу производителя и бренду из полных проверенных FTP-каталогов ЭТМ, затем проверенного реестра. Кэш каталогов до суток используется только для идентичности, не для остатков. Точные названия производителей FTP `SE Dekraft` и `SE Systeme` приведены к `DEKraft` и `Systeme Electric`. Для отсутствующих в FTP моделей дополнительно запрашивается goods API ЭТМ с проверкой артикула, производителя, названия и единицы «шт».
4. Обязательно обновить текущие остатки ЭТМ (принудительно оба склада), Русского Света и Feron. Успешное завершение подтверждается журналом и квитанциями. Ошибка любого источника откладывает отправку. Неоднозначные партии кабеля РС изолируются по модели, остальные товары продолжают обработку.
5. Под общей блокировкой соответствующего маркетплейса заново прочитать строки и отправить готовые товары. Ответ отправки и фактический остаток через API должны совпасть, только после этого сохраняется отметка готовности. Возраст самого раннего источника до отправки — не более 15 минут.

## Ограничения и повторные попытки

`logs/stream-onboarding-state.json` хранит обнаруженные артикулы, проверки единиц, свежесть источников и подтверждения Ozon/WB. Файл обязателен после установки: не удалять и не заменять пустым. Неизвестные новым регулярным отправщикам товары блокируются до подготовки; прежние товары продолжают обычную трансляцию. Для WB требуется реально существующий chrtId: он не создаётся из SKU Ozon и не угадывается. При его последующем появлении товар автоматически обрабатывается для WB.

Отсутствующий код ЭТМ повторно проверяется при изменении идентичности или через час. Неполные данные каталога, ошибки источников и занятые блокировки повторно обрабатываются на следующем проходе. Строки с неподтверждённой единицей продажи остаются на проверке; их остатки не публикуются автоматически.

`РУССКИЙ СВЕТ МОСКВА` остаётся выключенным: формула X новых строк равна нулю. В AB используется N+S+V; AC остаётся M+X. Регулярный отправщик AC на WB 1449484 — `sync-feron-stocks.js`. Аудит WB сохранён.

Найденный фактический chrtId автоматически передан на WB с успешной сверкой.

Единственная незавершённая позиция Ozon — `32491DEK-1` (отказ площадки выше). На WB подтверждён один товар с фактической карточкой; остальные ожидают реального chrtId. Живой допуск регулярного отправщика пропускает ровно 272 подготовленных товара Ozon. Москва остаётся выключенной. `pending=272` в сводке включает 272 отсутствующие карточки WB, а не 272 ошибки Ozon.

## Исправления 21.10.2026

По просьбе пользователя интервал подготовки изменён с 15 минут на 2 часа, WatchPaths удалён, установленный LaunchAgent перезагружен и проверен (`run interval = 7200 seconds`). Это не меняет 15-минутное ограничение возраста источников перед отправкой. Прямой источник остатков ИЭК не добавляется: пользователь подтвердил трансляцию товаров ИЭК через существующие ЭТМ/Русский Свет.

Обнаружены пустые StreamSupps V1/X1: строгая проверка заголовков останавливала все проходы. Восстановлены только прежние заголовки `РЕЗЕРВ` и `РУССКИЙ СВЕТ МОСКВА`, с резервной копией и точной сверкой. Значения и настройки Москвы не включались.

В автодобавлении отсутствовал UNIT API, хотя ТЗ/StreamSupps уже покрывали полный текущий каталог Ozon. В TARGETS Ozon добавлен UNIT API; записано 458 недостающих артикулов с проверкой read-back.

Уточнение от 21.10.2026: recurring missing-only repair существующих формул отменён. Первоначальная подготовка допускается только для новых уникальных строк в конце через append_initialization_ledger.js, все текущие строки защищены. Пользовательские удаления не восстанавливаются; canonical AG и заголовки массивов автоматически не мигрируются. См. Docs/append_only_formulas_audit_20261021.md. Интервал подготовки 7200 секунд сохранён.
